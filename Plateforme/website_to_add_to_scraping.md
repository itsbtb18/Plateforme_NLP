## corpus websites:
General NLP / AI corpus hubs

These sites host many multilingual or language‑independent text corpora that you can use for NLP / AI:

    NaturalLanguageProcessing.com – NLP text corpus list
    Table‑style list of many corpora (including Arabic ones) with links and license info.
    → https://naturallanguageprocessing.com/nlp-text-corpus/

    Stanford NLP – Statistical NLP / corpus links
    Old but still useful index of corpus‑based and statistical‑NLP resources.
    → https://www‑nlp.stanford.edu/links/statnlp.html

    Hugging Face Datasets / Datasets Hub
    Massive directory of datasets (including many NLP corpora); search by “arabic”, “NLP”, “text”, etc.
    → https://huggingface.co/datasets

    Kaggle Datasets – NLP section
    Many downloadable text corpora (news, tweets, reviews, etc.) suitable for NLP / AI.
    → https://www.kaggle.com/datasets (search “NLP”, “text”, “language”)

    AutoNLP – Arabic datasets list
    Curated list of 48+ Arabic‑language datasets (News, tweets, dialects, QA, etc.) for ML/NLP.
        → https://autonlp.ai/datasets‑list/arabic‑language

Arabic‑specific corpus websites

These focus directly on Arabic NLP corpora:

    ArabicNLP.uk – Datasets & corpora
    Open‑source Arabic NLP datasets, including summarisation, financial‑news, dialect, and readability corpora.
    → https://arabicnlp.uk

    NNLP‑IL / Arabic‑Resources (GitHub)
    Comprehensive list of Arabic NLP corpora:

        ArCOV‑19 (COVID‑19 Arabic tweets)

        Habibi (Arabic song‑lyrics corpus)

        PADIC (parallel Arabic dialect corpus)

        DART, MSDA, Kawarith (dialect, opinion, crisis‑event corpora)

        QASR (Al Jazeera speech corpus)
        → https://github.com/NNLP‑IL/Arabic‑Resources

    NYU Abu Dhabi – Arabic NLP lab (corpus‑related work)
    Research page pointing to Arabic NLP corpora and tools (often linked to CAMeL Tools and datasets).
        → https://nyuad.nyu.edu/en/research/faculty‑labs‑and‑projects/computational‑approaches‑to‑modeling‑language‑lab/research/arabic‑natural‑language‑processing

    Large and diverse Arabic corpus for language modeling (SciDirect)
    Paper describing a 500+ GB Arabic text corpus built for training large language models.
    → https://www.sciencedirect.com/science/article/pii/S1877050923011419

    Arabic‑learner and Arabic‑web corpora (ALC, arWaC)
    Listed on the NLP corpus directory; both are downloadable Arabic text collections.

        Arabic Learner Corpus (ALC)

        Arabic Web Corpus (arWaC)
        → https://naturallanguageprocessing.com/nlp‑text‑corpus/

Arabic‑focused NLP community / catalogues

These sites aggregate or point to many Arabic NLP corpora:

    SIGARab – Arabic NLP community
    Community portal that links to Arabic NLP datasets, tools, and events (including the Arabic NLP School).
    → https://www.sigarab.org

    SIGARab “Masader Arabic NLP Data Catalogue”
    Catalogue of Arabic NLP data sources (corpora, datasets, tools).
    → Linked from the SIGARab front page under “Masader Arabic NLP Data Catalogue”

    Research articles on “New Language Resources for Arabic”
    Describes a multi‑million‑word Arabic corpus with a corpus‑processing tool; useful if you want large‑scale Arabic text.
    → https://discovery.researcher.life/article/new‑language‑resources‑for‑arabic
